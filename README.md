# TaskFlow
Gestor local de tareas Android en Java y SQLite. Abre esta carpeta en Android Studio, sincroniza Gradle (8.9, JDK 17, SDK 35), luego Build > Generate App Bundles or APKs > Generate APKs. El archivo estará en app/build/outputs/apk/debug/app-debug.apk. No requiere internet durante el uso. Proyecto fuente no compilado ni probado en dispositivo.
